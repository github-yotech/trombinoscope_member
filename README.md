# trombinoscope_member
Odoo Trombinoscope Member Website

## Functionality

### In Configuration → Trombinoscope
- Placeholder: Display a default image when no picture is available
- List: Define the display order of members in the trombinoscope

### In the Trombinoscope Front Page
- Search bar: Search for members
- Search filters: Choose what to search (all members, company name, or contact name)
- Sort by tag: Order members based on their tags
- Sort alphabetically: Order members alphabetically
